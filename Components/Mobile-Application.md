# Мобільний застосунок

## Відповідальність
Клієнт React Native + Expo + TypeScript для Android. Надає рольові інтерфейси [[Passenger]] і [[Driver]], мапу, створення замовлення, виконання та історію. Запланована директорія коду: mobile/. Реалізація ще не підтверджена.

## Входи та виходи
Входи: дії користувача, дозволена геолокація, відповіді [[Backend-API]], події [[Realtime-Updates]]. Виходи: авторизовані API-запити, відображені [[Route]], [[Fare-Quote]] та [[Ride]].

Клієнт не встановлює остаточну ціну, роль або статус. [[Mapping-Integration]] відокремлюється адаптерами. Токени зберігаються в захищеному сховищі; серверні ключі не включаються в пакет застосунку.

## Помилки та перевірки
Передбачені відмова дозволу геолокації, відсутність мережі, помилки адрес і маршруту, прострочена пропозиція, конфлікт прийняття. Повтор створення використовує той самий ключ ідемпотентності. Після перепідключення стан перечитується.

Компонентні тести перевіряють ручний вибір адрес, повідомлення про помилки й дії за статусами; інтеграційні — взаємодію з API. Стек: [[ADR-001-Technology-Stack]].
