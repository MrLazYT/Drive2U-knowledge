# Мапа, адреси та маршрутизація

## Відповідальність
Інтеграція складається з трьох можливостей: відображення мапи, пошук/визначення адрес і побудова автомобільного [[Route]]. Вони можуть мати різних постачальників.

## Стан рішення
Конкретні SDK та постачальники ще не обрані. Перед вибором перевіряються сумісність React Native/Expo, Android-збірка, покриття міста, ліцензія, атрибуція, ціна, квоти та дозволене кешування. Безкоштовність не припускається. Рішення потрібно зафіксувати окремим ADR після перевірки.

## Межі
[[Mobile-Application]] показує мапу та результати пошуку. [[Backend-API]] виконує довірений розрахунок відстані для [[Fare-Quote]] через серверний адаптер. Внутрішні моделі не повинні залежати від формату конкретного провайдера.

## Захист і відмови
Серверні ключі не передаються клієнту. Ключі мобільного SDK обмежуються доступними засобами постачальника. Є ліміти, тайм-аути й контроль повторів. Без маршруту замовлення з ціною не створюється.

## Перевірка
Модульні тести використовують явні контрольовані відповіді адаптера: успіх, відсутня адреса, недоступний шлях, тайм-аут, вичерпана квота. Окремо перевіряється реальна інтеграція; контрольовані відповіді не видаються за дані провайдера.
