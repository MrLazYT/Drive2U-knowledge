# Оновлення стану в реальному часі

## Відповідальність
SignalR повідомляє учасників [[Ride]] про вже збережені зміни стану. Він доповнює [[Backend-API]], але не замінює його як джерело істини. Постійна GPS-трансляція не є частиною цього початкового контракту.

## Дані та доступ
Подія містить ідентифікатор замовлення, статус і версію стану; мінімально необхідні дані повертаються відповідно до повноважень. Сервер визначає право приєднання до каналу; знання ID поїздки не надає доступу.

[[Mobile-Application]] відкидає застарілі події. Після розриву та повторного підключення запитує поточний стан через API. Втрата каналу не скасовує замовлення автоматично. Гарантія доставки кожної події не припускається.

## Перевірка
Чужа підписка відхиляється, застарілий статус не повертає UI назад, пропущена подія компенсується перечитуванням, завершена транзакція передує повідомленню. Стани: [[Ride-Lifecycle]]; терміни: [[Project-Glossary]].
