# Глосарій Drive2U
| Термін              | Визначення                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------------- |
| Passenger / Пасажир | Користувач, який замовляє перевезення; [[Passenger]].                                           |
| Driver / Водій      | Допущений виконавець поїздки з профілем авто; [[Driver]].                                       |
| Ride / Замовлення   | Запис погодженої поїздки з учасниками, ціною й станом; [[Ride]].                                |
| FareQuote           | Пропозиція ціни для визначених точок зі строком дії; [[Fare-Quote]].                            |
| Route / Маршрут     | Автомобільний шлях, геометрія, відстань і орієнтовна тривалість; [[Route]].                     |
| Tariff / Тариф      | Версія правил обчислення ціни: подача та ставка/км; [[Fare-Quote]].                             |
| Geocoding           | Перетворення адреси в координати; [[Mapping-Integration]].                                      |
| Reverse geocoding   | Визначення адреси за координатами; [[Mapping-Integration]].                                     |
| Routing             | Побудова автомобільного маршруту між точками; [[Route]].                                        |
| ETA                 | Оцінка часу прибуття; не гарантія та не тотожна тривалості маршруту.                            |
| Availability        | Готовність водія приймати замовлення; [[Driver]].                                               |
| Active ride         | Замовлення в активному статусі; перелік залежить від ролі, [[Ride-Lifecycle]].                  |
| Idempotency         | Повтор тієї самої операції не створює додаткового результату; [[Backend-API]].                  |
| Concurrency control | Запобігання конфліктним одночасним змінам; [[ADR-002-Server-Authority]].                        |
| SignalR             | Канал оперативних повідомлень про стан; [[Realtime-Updates]].                                   |
| ADR                 | Документ контексту, рішення, альтернатив і наслідків; [[ADR-001-Technology-Stack]].             |
| MOC                 | Навігаційна нотатка-хаб; [[MOC-Drive2U]].                                                       |
| Vault               | Окреме сховище пов’язаних Markdown-нотаток; [[Conventions]].                                    |
| MCP connector       | Типізований інтерфейс агентного читання та запису знань, запланований окремо; [[Conventions]].  |
| Harness             | Інфраструктура знань, процедур, інструментів і обмежень для агентної розробки; [[Conventions]]. |

Визначення підтримуються відповідно до джерел. Нове визначення не змінює бізнес-правило без погодження документа вимог.
