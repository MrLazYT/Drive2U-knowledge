# ADR-001 — технологічний стек

## Контекст
Drive2U має мобільні інтерфейси пасажира й водія, [[Route]], авторизацію та оперативне оновлення [[Ride]]. Розробка ведеться у VS Code; клієнт і сервер потребують чітких контрактів та автоматизованих перевірок.

## Рішення
[[Mobile-Application]]: React Native + Expo + TypeScript. [[Backend-API]]: ASP.NET Core Web API, C#, Identity, EF Core, початково SQLite. [[Realtime-Updates]]: SignalR. Тести: xUnit, Jest, React Native Testing Library. Перший цільовий пристрій — Android.

Рішення прийняте як напрям архітектури; версії ще не зафіксовані. [[Mapping-Integration]] обирається окремо після перевірки SDK та умов постачальників.

## Альтернативи
.NET MAUI дозволяє C# на клієнті, але обрано React Native відповідно до рішення розробника. Нативний Android потребував би окремої клієнтської реалізації для iOS. Серверна СУБД надає кращі можливості багатовузлового розгортання, але збільшує початкову інфраструктуру.

## Наслідки й перегляд
Потрібні TypeScript і C#, сумісні контракти та контроль двох екосистем залежностей. SQLite придатність перевіряється тестами конкурентних записів. Перед масштабуванням оцінюється серверна СУБД. Потреба нативного SDK може вимагати Expo development build; можливості збірки перевіряються перед інтеграцією.
